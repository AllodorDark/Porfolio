## 🍕 Функциональное и UI/UX тестирование веб-приложения — Make Love Pizza

Практический пет-проект по ручному тестированию клиентской части (Frontend) сайта службы доставки пиццы **Make Love Pizza**. 

Цель проекта — провести проверку критически важного пользовательского функционала (авторизация, навигация, работа элементов главной страницы) и проанализировать сетевые запросы и состояние хранилища браузера через **Chrome DevTools**.

---

## 🛠 Стек и инструменты
* **Тест-менеджмент:** Test IT
* **Анализ сети и хранилища:** Chrome DevTools (вкладки Network, Application / Local Storage, Cookies)
* **Виды тестирования:** Функциональное, UI/UX, негативное, граничные значения

---

## 📋 Что было сделано

В системе **Test IT** спроектирована и структурирована тестовая документация, разделенная на 3 логических модуля (всего **12 тест-кейсов**)[Скачать XLSX-таблицу (Table(mlp).xlsx)](./Table(mlp).xlsx):

### 1. Модуль «Авторизация» (7 тест-кейсов)
Проверена работа формы входа по номеру телефона:
* Позитивные сценарии (валидный номер телефона, подтверждение входа).
* Негативные сценарии и граничные значения (невалидный формат номера, пустые поля).

### 2. Модуль «Навигация и Главная страница» (3 тест-кейса)
Проведена проверка основных структурных блоков интерфейса и переходов:
* **`Header`:** корректность отображения меню, логотипа, кнопок навигации и выбора города/адреса.
* **`Main`:** работа основного контента, карточек товаров, баннеров и интерактивных элементов.
* **`Footer`:** проверка ссылок, контактов, юридической информации и соцсетей.

### 3. Модуль «DevTools» (2 тест-кейса)
Выполнена техническая проверка работы фронтенда «под капотом» с помощью инструментов разработчика:
* **Вкладка Network:** анализ HTTP-запросов, проверка корректности статус-кодов ответов сервера при взаимодействии с сайтом.
* **Вкладка Application:** проверка сохранения состояния сессии/корзины и пользовательских данных в хранилище браузера (`Local Storage` / `Cookies`) после перезагрузки страницы.
